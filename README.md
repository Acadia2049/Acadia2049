# Shilin Liu

I build web applications with LLMs and work with behavioral data in Python. My interests include human–AI interaction, online participation, and reliable tools for empirical research.

## Selected work

### [NYC After Dark](https://github.com/Acadia2049/coms6998)

An independently developed AI-assisted writing application: people supply an idea, edit a generated draft, and decide when to publish. Built with Next.js, TypeScript, Supabase, and a server-side LLM API. Companion applications provide prompt-chain execution and administrative tools.

[Try the application](https://coms6998-sand.vercel.app/)

### [Online Shoppers Purchase Prediction](https://github.com/Acadia2049/online-shoppers-purchase-prediction)

Python/PySpark analysis of online shopping sessions, including data checks, exploratory analysis, four classification models, purchase-class metrics, and a feature ablation using the same train/test split. The project examines predictive associations rather than causal treatment effects.

## Tools

TypeScript / JavaScript · React / Next.js · Supabase / PostgreSQL · LLM APIs · Python / PySpark
